# Справочник марок и моделей транспорта

**Марки и модели транспорта в CSV и JSON.**

[English](README.md) · [CSV](vehicles.csv) · [JSON](vehicles.json)

Справочник подходит для списков выбора, поиска и нормализации названий транспорта. В нём есть легковые автомобили, грузовая техника, мотоциклы и другие виды транспорта. В каждой строке указаны категория, марка и модель.

## Файлы и формат

| Файл | Содержимое |
| --- | --- |
| [vehicles.csv](vehicles.csv) | Таблица в кодировке UTF-8 со строкой заголовков. |
| [vehicles.json](vehicles.json) | Массив JSON в кодировке UTF-8 с теми же записями в том же порядке. |

В каждой записи три поля.

| Поле | Значение |
| --- | --- |
| `category` | Код категории транспорта, например `passenger_car` или `motorcycle`. |
| `brand` | Название марки в справочнике. |
| `model` | Название модели этой марки в справочнике. |

```json
{
  "category": "passenger_car",
  "brand": "Abarth",
  "model": "124 Spider"
}
```

## Источники и проверка

По описанию составителя, записи собирались вручную. Марки и модели искали по отдельности и сверяли по общедоступным источникам, в том числе по сайтам и архивам производителей, где это было возможно. Ссылки сохранились для части записей.

Выгрузку проверили на дубли названий внутри категории или марки, некорректные символы и расхождения между категориями марки и модели. Названия легковых автомобилей дополнительно сверили с внешними каталогами.

## Как предложить исправление

Укажи категорию, марку и модель в том виде, в каком они записаны в справочнике, предложи исправление и приложи ссылку на общедоступный источник. Для регионального названия укажи рынок и поясни, как связаны варианты названия.
